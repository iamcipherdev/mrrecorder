# MrRecorder

**MrRecorder** is a free, creator-focused screen recorder and editor — record your screen, polish it with auto-zoom, cursor effects and captions, and export reels-ready vertical video in one click.

Built on [Recordly](https://github.com/webadderallorg/Recordly) (AGPL-3.0). See [ATTRIBUTION](#attribution) below.

## What's new in MrRecorder

- **Reel Mode** — one click: 9:16 canvas + auto-captions + 1080×1920 export preset. Made for demo videos that go straight to Instagram Reels / TikTok.
- **Branded intro/outro** — optional title cards in your brand style, added at export.
- **MrRecorder branding** — new name, icon, and identity throughout.

Everything Recordly does still works: auto-zoom, cursor effects, backgrounds, annotations, multi-language captions, MP4/GIF export.

## Install

Prebuilt releases (macOS / Windows / Linux): see [Releases](https://github.com/iamcipherdev/mrrecorder/releases).

Or build from source:

```bash
git clone https://github.com/iamcipherdev/mrrecorder.git
cd mrrecorder
npm install
npm run dev        # dev mode
npm run build      # packaged build (platform-specific: build:mac / build:win / build:linux)
```
